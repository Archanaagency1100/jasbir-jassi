Interactions
  Fixed left navigation tracks the current section.
  Releases, videos, gallery and press have manual carousels.
  Four cards are visible at desktop widths over 1100px.
  Use arrows, mouse dragging, horizontal scrolling, touch swipe or arrow keys.
  Carousels never advance automatically.
  Photographs and press scans open in a full-size lightbox with zoom.
  Entry animations and a subtle copper cursor follower are included.
  Reduced-motion settings disable decorative movement.

Edit assets/site.css for layout and colour, assets/site.js for interactions,
